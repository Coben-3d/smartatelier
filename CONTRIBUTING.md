# Contribuer

Merci de garder SmartAtelier simple : une application personnelle et locale.

Pour proposer une modification : créez une branche, expliquez le problème, ajoutez des tests qui protègent le comportement concerné, puis exécutez `npm test`, `npm run build` et `npm run release:check`.

Aucun test automatique ne doit consommer un abonnement IA. Utilisez des données synthétiques pour les tests ; documentez séparément les essais réels. N’ajoutez ni photo personnelle, ni export de stock, ni journal de connexion.

Précisez votre système, les versions Node/CLI, la marche à suivre et le résultat attendu dans les rapports de bug. Masquez les emails, codes de connexion, tokens, notes personnelles et chemins privés. Les retours Windows/Linux et les photos de bobines publiables sont particulièrement utiles.
